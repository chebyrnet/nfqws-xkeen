# CLI и меню

```sh
nfqws-xkeen          # меню
nfqws-xkeen status
nfqws-xkeen enable
nfqws-xkeen disable
nfqws-xkeen repatch
nfqws-xkeen doctor
nfqws-xkeen check
nfqws-xkeen update
nfqws-xkeen uninstall
```

| Команда | Действие |
|---|---|
| `status` | патч, блок conf, процесс, iptables |
| `enable` | блок + патч + restart |
| `disable` | `XKEEN_MARK_ONLY=0` |
| `repatch` | после обновления nfqws2 |
| `doctor` | диагностика |
| `check` / `update` | GitHub releases |

> Плейсхолдер под скрин меню CLI.
