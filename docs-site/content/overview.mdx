# Обзор настройки связки

Цель: часть трафика идёт мимо VPN, но через **nfqws2**; остальное — через proxy-группы mihomo.

1. Установить nfqws2 и XKeen (mihomo).
2. Установить [nfqws-xkeen](/install).
3. Добавить proxy NFQWS — [mihomo](/mihomo-setup).
4. Направить нужные rules на NFQWS.
5. `nfqws-xkeen doctor` и счётчики iptables.

> Плейсхолдер под скрин/схему.
