# nfqws-xkeen

Пакет для Keenetic + Entware: направляет в **nfqws2** только трафик, который mihomo пометил outbound’ом **NFQWS** (`routing-mark`).

## Идея

```text
клиент → XKeen/mihomo
       → outbound NFQWS (direct + routing-mark 0x10000000)
       → штатные правила nfqws2 (POLICY_MARK = эта метка)
       → NFQUEUE → nfqws2 (DPI desync)
```

Вместо своей урезанной iptables-цепочки пакет **патчит** `S51nfqws2`, чтобы nfqws2 сам строил полный firewall, но фильтровал по метке mihomo.
