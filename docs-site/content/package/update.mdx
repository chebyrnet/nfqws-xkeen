# Обновления

## Обновился nfqws2

Так бывает чаще всего: вы обновили nfqws2 через opkg или веб, и интеграция с mihomo перестала работать, потому что init-скрипт перезаписан.

Сделайте:

```sh
nfqws-xkeen repatch
nfqws-xkeen doctor
```

Если doctor ругается на блок conf (маркеры пропали после ручного сохранения конфига в вебе), выполните ещё:

```sh
nfqws-xkeen enable
```

## Обновить сам nfqws-xkeen

Посмотреть, есть ли новая версия:

```sh
nfqws-xkeen check
```

Поставить обновление:

```sh
nfqws-xkeen update
```

Либо снова one-liner с GitHub (`install.sh`). Если блок настроек в `nfqws2.conf` уже есть, повторная установка **не затирает** ваши значения `XKEEN_*` - только следит, чтобы ключи на месте.

## Бэкапы

Всегда смотрите `/opt/var/lib/nfqws-xkeen/`, если нужно откатить файл вручную.
