# Команды и меню

После установки в системе появляется команда `nfqws-xkeen`.

Запуск без аргументов открывает цветное меню. Те же действия доступны и одной строкой.

## Список команд

| Команда | Что делает |
|---------|------------|
| `nfqws-xkeen` или `nfqws-xkeen menu` | Интерактивное меню |
| `nfqws-xkeen status` | Показывает версию, есть ли патч, блок conf, запущен ли nfqws2, кусок iptables |
| `nfqws-xkeen enable` | Включает интеграцию: блок conf, патч S51, перезапуск nfqws2 |
| `nfqws-xkeen disable` | Ставит `XKEEN_MARK_ONLY=0` и перезапускает nfqws2 (патч остаётся, но не фильтрует по mihomo) |
| `nfqws-xkeen repatch` | Заново накладывает патч на S51 (нужно после обновления nfqws2) |
| `nfqws-xkeen doctor` | Короткая диагностика типичных проблем |
| `nfqws-xkeen check` | Сравнивает локальную версию с GitHub |
| `nfqws-xkeen update` | Обновляет пакет через remote install |
| `nfqws-xkeen uninstall` | Снимает патч и блок conf |
| `nfqws-xkeen help` | Справка |

## Полезные переменные окружения

Их обычно не трогают, но они есть для отладки и тестов:

- `S51_PATH` - путь к init-скрипту nfqws2
- `NFQWS2_CONF` - путь к конфигу nfqws2
- `NFQWS_XKEEN_STATE_DIR` - каталог бэкапов
- `NO_COLOR=1` - отключить цвета в выводе
