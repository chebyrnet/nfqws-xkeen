# Тонкости nfqws2

## Режим списков доменов

Когда mihomo уже решает, какой трафик отдавать в NFQWS, повторная фильтрация доменов внутри nfqws2 часто не нужна. В `/opt/etc/nfqws2/nfqws2.conf` можно поставить:

```sh
NFQWS_EXTRA_ARGS="$MODE_ALL"
```

Стратегии desync (`NFQWS_ARGS`, QUIC, UDP) пакет **не меняет**. Их вы настраиваете сами под своего провайдера.

## Интерфейс и номер очереди

В том же `nfqws2.conf` смотрите:

- `ISP_INTERFACE` - WAN-интерфейс (часто `eth3`, бывает несколько через пробел);
- `NFQUEUE_NUM` - номер очереди (у nfqws2 часто `300`).

После правки:

```sh
/opt/etc/init.d/S51nfqws2 restart
```

## Если веб-редактор снёс блок nfqws-xkeen

Некоторые веб-морды при сохранении conf могут повредить маркеры `BEGIN`/`END`. Тогда:

```sh
nfqws-xkeen enable
```

или

```sh
nfqws-xkeen repatch
```
